# CC-10: Medical ID and scenario backend

- Author: Codex. Branch: `codex/cc-10-scenario`, stacked on CC-08.
- Status: backend ready for review. UI integration is pending CC-09; task is not complete.

## Delivered

Synthetic profile writes/revocation, scoped consent, caller-is-patient assertion, active-incident authorization and audit events. Profile values live separately from immutable events, including response receipts. Revocation clears stored values and a replayed access receipt cannot restore them. Value reads recheck consent/session/status under the database writer transaction. The demo has no authentication; bind only to localhost.

Spatial/time duplicate blocking (150 m, 300 s) flags candidates and retains distinct incidents and original fact/report provenance; no automatic merge. E5 is optional and not installed. An explicit merge-resolution UI/API remains follow-up work; candidates do not silently remove demand.

`POST /demo/advance` enforces T+0 → T+2 → T+5 → T+10. It logs cardiac symptoms, non-emergency queries/tyre assistance, accident/gas evacuation, flood/duplicate reports, and A2 breakdown plus school collapse. A1 becomes on-scene at T+2 when its assignment was delivered. Each step has a single global planning tick. Step requests are idempotent. Medical destinations are capacity constrained and pre-alerts are simulated outbox events.

## Verification

`cd backend && uv run python -m app.scenario --output ../evals/scenario-smoke.json` runs the real offline road router, allocation, explicit synthetic approvals, delivery and replay in a disposable database. `uv run pytest tests/test_demo_privacy.py tests/test_planning_flow.py` covers privacy/receipt revocation, event confidentiality, step order/retries, duplicate candidates, replay and simulated pre-alerts.

The smoke artifact is one four-stage demonstration, not the independent CC-11 100-seed benchmark. Unsupported water navigation stays visibly unmet. Profile endpoints are documented by OpenAPI. Claude owns wiring them to the console after CC-09.
