# Demo pack (CC-13)

- [SCRIPT.md](SCRIPT.md): the timed 8-minute presentation, T+0 → T+10. It covers the plan diff, approval, override, duplicates, Medical ID and the offline or failure behaviour. Each beat was checked against the running system.
- [CLAIMS.md](CLAIMS.md): what may be claimed (measured, with evidence and the command to reproduce it), design properties, hypotheses that must not be stated as results, and limitations.
- [FALLBACK.md](FALLBACK.md): what to do when something fails live, a screenshot deck and a rehearsal checklist.

Run it with `scripts/demo.sh` (see `docs/RUN-DEMO.md`). Whether to publish or deploy is the user's decision; nothing here does either.
